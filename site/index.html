Plane for Zapier (Unofficial)

Connect Plane to thousands of apps: create work items from forms and emails, find them, and act the moment new ones appear, without writing code.

The problem

Plane has no app in the Zapier directory. Teams on Plane copy form responses, support emails and alerts into Plane by hand, then announce new work in Slack by hand too.

What it does

Four building blocks you can combine with any of Zapier's apps.

Trigger

New Work Item

Starts a Zap when a work item is created in a project you choose.

Action

Create Work Item

Creates a work item with title, description, priority, state and labels.

Search

Find Work Item

Finds a work item by exact title or identifier, such as WEB-42.

Find or create

Find or Create

Finds a matching item in the chosen project, or creates it if none exists.

  • Dropdowns for project, state and labels, reloaded when the project changes.
  • Plain-language errors for a bad key, wrong workspace, missing access and rate limits.
  • Within Plane's limit of 60 requests a minute, and every step finishes within 30 seconds.
  • Cloud and self-hosted: works with Plane Cloud and Community Edition.

How to connect

It takes about a minute. You need your own Plane account; the free plan works.

  1. Get a personal access token

    In Plane, open Profile settings → Personal Access Tokens and create a token.

  2. Enter it with your workspace slug

    In Zapier, paste the token as the API key and add your workspace slug: acme in app.plane.so/acme/…

  3. Self-hosted? Add your URL

    Optional. Leave blank for Plane Cloud. For self-hosted Plane, enter your instance URL. It must use HTTPS and be reachable from the internet.
