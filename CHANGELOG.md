## 1.0.0

First release, a private integration you join by invite.

- New trigger **New Work Item** (`new_work_item`): starts a Zap when a work item is created in the chosen project.
- New action **Create Work Item** (`create_work_item`): title, description, priority, state and labels.
- New search **Find Work Item** (`find_work_item`): finds a work item by identifier (e.g. `WEB-42`) or exact title within a project.
- New **Find or Create Work Item**: searches in the chosen project and creates the item if nothing matches.
- API-key connection for Plane Cloud and self-hosted Plane (HTTPS), with plain-language error messages.
